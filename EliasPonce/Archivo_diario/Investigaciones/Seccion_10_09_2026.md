# 1. Propósito y Alcance de esta Investigación de Código
El objetivo principal de este análisis es estudiar cómo diferentes lenguajes de programación resuelven un mismo problema básico: **interactuar con el usuario, procesar variables y mostrar información por pantalla**.

### ¿Qué se analiza en esta investigación?
* **Evolución de la Sintaxis:** Se observa cómo lenguajes más antiguos y visuales (como VBA) se enfocan en interfaces directas, mientras que lenguajes estructurados (como Java y Dart) priorizan la seguridad de los datos mediante el tipado estricto.
* **Manejo de Memoria y Tipos:** Se analiza la diferencia entre lenguajes que transforman automáticamente los datos al unirlos (VBA y Java con la concatenación implícita) frente a los que exigen una conversión manual y explícita (`.toString()` en Dart o `Integer.parseInt()` en Java).
* **Paradigmas de Ejecución:** Se contrasta el flujo de un programa de consola web (Java Online), un script nativo (Dart) y una macro automatizada de escritorio (VBA).

Esta comparativa sirve como base para comprender los fundamentos de la **portabilidad, abstracción y diseño de software** al migrar lógica de negocio entre diferentes plataformas tecnológicas.
