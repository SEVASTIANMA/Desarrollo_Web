# Investigación: Comparativa entre Python y Dart

## 1. Definición y Propósito
**Python** es un lenguaje interpretado de alto nivel muy enfocado en ciencia de datos, inteligencia artificial y scripting general por su sintaxis limpia. **Dart**, desarrollado por Google, está optimizado para desarrollo multipataforma (móvil, web y escritorio) mediante frameworks como Flutter.

---

## 2. Lógica de Tipado
* **Python:** Utiliza tipado dinámico (las variables adaptan su tipo en tiempo de ejecución).
* **Dart:** Permite tipado estático opcional (`int`, `String`) ayudando a detectar errores antes de compilar.

---

## 3. Ejemplo Conceptual

```python
# Python
mensaje = "Hola mundo en Python"
print(mensaje)
```

// Dart
String mensaje = "Hola mundo en Dart";
print(mensaje);

---

## 4. Cuadro Comparativo: Python vs. Dart

| Criterio | Python | Dart |
| :--- | :--- | :--- |
| **Paradigma** | Multiparadigma (Orientado a objetos, imperativo) | Orientado a objetos basado en clases |
| **Uso Principal** | IA, Backend, Automatización, Ciencia de Datos | Desarrollo de Apps móviles (Flutter) y Web |
| **Tipado** | Dinámico | Estático y Seguro (*Sound Null Safety*) |

---

## 5. Análisis de Complejidad Temporal

* **Ejecución:** Python depende de su intérprete (más lento en tareas pesadas sin librerías de C), mientras que Dart compila tanto a código nativo (AOT) como a JavaScript (JIT), ofreciendo alto rendimiento gráfico.

---

## 6. Conclusión
Conocer ambos lenguajes dota al desarrollador de una gran versatilidad: Python domina el backend y el análisis lógico, mientras que Dart sobresale en la creación de interfaces de usuario interactivas y aplicaciones móviles modernas.
