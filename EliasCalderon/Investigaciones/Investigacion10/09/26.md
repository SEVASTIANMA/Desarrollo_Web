# Investigacion JAVA

import java.util.Scanner;

public class PruebaConsole {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("¿Cuántos años tienes? ");
        String a = scanner.nextLine();
        
        System.out.println("Tienes " + a + " años");
        
        scanner.close();
    }
}

 ### Explicación del funcionamiento

* **`Scanner scanner = new Scanner(System.in);`**: Inicializa la clase `Scanner` apuntando a la entrada estándar (`System.in`), lo que permite capturar los datos que el usuario escribe desde el teclado.
* **`System.out.print(...)`**: Muestra la pregunta en la terminal sin dar un salto de línea, permitiendo que el usuario responda en la misma fila.
* **`String a = scanner.nextLine();`**: Pausa el programa y espera a que el usuario presione *Enter*. Captura toda la línea escrita y la almacena como texto en la variable `a`.
* **`System.out.println(...)`**: Concatena el valor de la variable `a` con el texto complementario y lo imprime en la pantalla con un salto de línea final.
* **`scanner.close();`**: Finaliza el flujo de lectura para liberar los recursos del sistema operativo que el programa estaba utilizando.
